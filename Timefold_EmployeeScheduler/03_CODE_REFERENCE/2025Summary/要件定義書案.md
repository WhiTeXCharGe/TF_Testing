# 制約の定式化

## ValueRange / Candidate Filtering

### スキルマップ

- 適用技術：ValueRangeProvider / candidate filtering
    
- 必要スキルを満たす作業者のみを `CrewSeat` の候補集合に含める
    
- 詳細：
    

Es={ e∈E∣skill(e,op(s))>0 }\mathcal{E}_s = \{\, e \in \mathcal{E} \mid \mathrm{skill}(e,\mathrm{op}(s)) > 0 \,\}Es​={e∈E∣skill(e,op(s))>0} employee(s)∈Es\mathrm{employee}(s) \in \mathcal{E}_semployee(s)∈Es​

※ 現コードでは `eligibleEmployeesForSeat` に入る候補集合を事前に作る構成であり、違反に対して直接 HardScore を課す方式ではない。

### 作業責任者制約

- 適用技術：ValueRangeProvider
    
- 管理者席には管理者のみ割当可能
    
- 詳細：
    

Esmgr={ e∈Es∣isManager(e)=1 }\mathcal{E}^{mgr}_s = \{\, e \in \mathcal{E}_s \mid \mathrm{isManager}(e)=1 \,\}Esmgr​={e∈Es​∣isManager(e)=1} needManager(s)=1⇒employee(s)∈Esmgr\mathrm{needManager}(s)=1 \Rightarrow \mathrm{employee}(s)\in \mathcal{E}^{mgr}_sneedManager(s)=1⇒employee(s)∈Esmgr​

非管理者席では `UNASSIGNED` を候補に含めるが、管理者席では含めない。

### 固定席制約

- 適用技術：ValueRangeProvider / PlanningPin
    
- 固定席は固定作業者のみ、または固定作業者不在時の代替値のみを候補にする
    
- 詳細：
    

pinnedFixed(s)=1⇒Es={pinnedWorker(s)}\mathrm{pinnedFixed}(s)=1 \Rightarrow \mathcal{E}_s = \{\mathrm{pinnedWorker}(s)\}pinnedFixed(s)=1⇒Es​={pinnedWorker(s)}

固定席は `isPinned()` により solver 変更対象外となる。

### 開始日候補

- 適用技術：ValueRangeFactory
    
- `BlockDecision.startDay` はウィンドウ範囲内から選ぶ
    
- 詳細：
    

startDay(b)∈[windowStart(b), windowEnd(b)]\mathrm{startDay}(b) \in [\mathrm{windowStart}(b),\ \mathrm{windowEnd}(b)]startDay(b)∈[windowStart(b), windowEnd(b)]

ただし phase 1 は現在コード上で `windowStart` のみを候補とする。

### 継続日数候補

- 適用技術：ValueRangeFactory
    
- `BlockDecision.days` は 1 日以上、ウィンドウ長以下
    
- 詳細：
    

days(b)∈{1,2,…,windowEnd(b)−windowStart(b)+1}\mathrm{days}(b) \in \{1,2,\dots,\mathrm{windowEnd}(b)-\mathrm{windowStart}(b)+1\}days(b)∈{1,2,…,windowEnd(b)−windowStart(b)+1}

### 作業時間候補

- 適用技術：ValueRangeProvider
    
- `BlockDecision.hours` は allowed hours の離散集合から選ぶ
    
- 詳細：
    

hours(b)∈Hb\mathrm{hours}(b) \in H_bhours(b)∈Hb​ Hb=allowedHours(b)H_b = \mathrm{allowedHours}(b)Hb​=allowedHours(b)

## 絶対制約

### 工程間順序

- 適用技術：HardScore
    
- 同一 module で phase p+1p+1p+1 は phase ppp の終了前に開始できない
    
- 詳細：
    

end(b)=startDay(b)+days(b)−1\mathrm{end}(b)=\mathrm{startDay}(b)+\mathrm{days}(b)-1end(b)=startDay(b)+days(b)−1 ∀(bp,bp+1), phaseNum(bp+1)=phaseNum(bp)+1\forall (b_p,b_{p+1}),\ \mathrm{phaseNum}(b_{p+1})=\mathrm{phaseNum}(b_p)+1∀(bp​,bp+1​), phaseNum(bp+1​)=phaseNum(bp​)+1 HardScore=−max⁡(0, end(bp)−startDay(bp+1)+1)\mathrm{HardScore} = -\max\left(0,\ \mathrm{end}(b_p)-\mathrm{startDay}(b_{p+1})+1\right)HardScore=−max(0, end(bp​)−startDay(bp+1​)+1)

### 工程開始日・終了日

- 適用技術：HardScore
    
- ブロック終了日が作業可能期間の終了を超えてはならない
    
- 詳細：
    

HardScore=−max⁡(0, startDay(b)+days(b)−1−windowEnd(b))\mathrm{HardScore} = -\max\left(0,\ \mathrm{startDay}(b)+\mathrm{days}(b)-1-\mathrm{windowEnd}(b)\right)HardScore=−max(0, startDay(b)+days(b)−1−windowEnd(b))

### 作業時間

- 適用技術：HardScore
    
- 選択した1日作業時間が allowed set に含まれない場合を違反とする
    
- 詳細：
    

hours(b)∉Hb⇒HardScore=−1\mathrm{hours}(b)\notin H_b \Rightarrow \mathrm{HardScore}=-1hours(b)∈/Hb​⇒HardScore=−1

### 必要作業量

- 適用技術：HardScore
    
- ブロックの実生産時間が必要時間を下回ってはならない
    
- 詳細：
    

P(b)=∑s∈Sb, employee(s)≠∅ ∑d∈W(b,s)hours(b)P(b)=\sum_{s\in S_b,\ \mathrm{employee}(s)\neq \varnothing}\ \sum_{d\in W(b,s)} \mathrm{hours}(b)P(b)=s∈Sb​, employee(s)=∅∑​ d∈W(b,s)∑​hours(b)

ここで W(b,s)W(b,s)W(b,s) は、ブロック期間内かつ工場・地域・顧客カレンダおよび個人不可日を通過した有効作業日集合。

HardScore=−10⋅max⁡(0, requiredHours(b)−P(b))\mathrm{HardScore} = -10\cdot \max(0,\ \mathrm{requiredHours}(b)-P(b))HardScore=−10⋅max(0, requiredHours(b)−P(b))

### 過剰投入上限

- 適用技術：HardScore
    
- 過剰投入は許容するが、柔軟席1人あたり概ね1日分を超える過剰は違反とする
    
- 詳細：
    

Pf(b)=flexible seats only productionP_f(b)=\text{flexible seats only production}Pf​(b)=flexible seats only production nf(b)=∣{s∈Sb∣s is flexible and staffed}∣n_f(b)=|\{s\in S_b \mid s \text{ is flexible and staffed}\}|nf​(b)=∣{s∈Sb​∣s is flexible and staffed}∣ HardScore=−max⁡(0, Pf(b)−requiredHours(b)−nf(b)⋅hours(b))\mathrm{HardScore} = -\max\left(0,\ P_f(b)-\mathrm{requiredHours}(b)-n_f(b)\cdot \mathrm{hours}(b)\right)HardScore=−max(0, Pf​(b)−requiredHours(b)−nf​(b)⋅hours(b))

### 複数作業不可

- 適用技術：HardScore
    
- 同一作業者・同一日における作業件数が 1 を超えてはならない
    
- 詳細：
    

N(e,d)=Ndyn(e,d)+Nfixed(e,d)N(e,d)=N^{dyn}(e,d)+N^{fixed}(e,d)N(e,d)=Ndyn(e,d)+Nfixed(e,d) HardScore=−max⁡(0, N(e,d)−1)\mathrm{HardScore} = -\max(0,\ N(e,d)-1)HardScore=−max(0, N(e,d)−1)

固定実績件数 `FIXED_TASKCOUNT_BY_EMP_DAY` を加算して判定する。

### 1日作業時間上限

- 適用技術：HardScore
    
- 同一作業者・同一日の総作業時間が `DAILY_CAP=12` を超えてはならない
    
- 詳細：
    

H(e,d)=Hdyn(e,d)+Hfixed(e,d)H(e,d)=H^{dyn}(e,d)+H^{fixed}(e,d)H(e,d)=Hdyn(e,d)+Hfixed(e,d) HardScore=−max⁡(0, H(e,d)−12)\mathrm{HardScore} = -\max(0,\ H(e,d)-12)HardScore=−max(0, H(e,d)−12)

### 移動日制約

- 適用技術：HardScore
    
- 異なる地域間で連続作業する場合、地域間移動日数を満たす必要がある
    
- 詳細：
    

r(d)=regionOfFab(fab(d))r(d)=\mathrm{regionOfFab}(\mathrm{fab}(d))r(d)=regionOfFab(fab(d)) g(ri,rj)=transitDays(ri,rj)g(r_i,r_j)=\mathrm{transitDays}(r_i,r_j)g(ri​,rj​)=transitDays(ri​,rj​)

隣接する異地域作業日に対し、日付差が必要移動日数より小さい場合を違反とする。  
コードは作業者ごとに日別 region 列を作成し、さらに履歴上の最終固定地域も起点に含めて判定する。

### 作業不可日制約

### 残業時間制約
