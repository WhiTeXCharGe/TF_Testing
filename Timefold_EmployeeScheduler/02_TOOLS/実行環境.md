## 実行環境

本プロジェクトは、Java と Maven を使用してビルド・実行する。  
必要なライブラリは Maven の `pom.xml` に定義されており、Maven 実行時に自動的に取得される。

| 項目 | 内容 |
|---|---|
| OS | Windows 11 |
| OSバージョン | 10.0 |
| アーキテクチャ | amd64 |
| Javaバージョン | Java 24.0.2 |
| Javaベンダー | Oracle Corporation |
| Java実行環境 | `C:\Program Files\Java\jdk-24` |
| Mavenバージョン | Apache Maven 3.8.8 |
| Mavenホーム | `C:\Program Files\apache-maven-3.8.8-bin\apache-maven-3.8.8` |
| 文字コード | UTF-8 |
| ライブラリ管理 | Maven（`pom.xml`） |
| 入力ファイル | `EnvConfig.yaml`, `Schedule.yaml` |
| メインクラス | `com.yourorg.scheduler.EmployeeSchedule` |

---

## 使用ライブラリ

本プロジェクトで直接使用している主なライブラリは以下の通りである。

| ライブラリ | バージョン | 用途 |
|---|---:|---|
| Timefold Solver Core | 1.27.0 | スケジューリング最適化 |
| SnakeYAML | 2.2 | YAMLファイルの読み込み |

---

## ビルド・実行方法

プロジェクトフォルダ直下で、以下のコマンドを実行する。

```bash
mvn -DskipTests clean package
mvn -q exec:java -D"exec.args=src/main/resource/EnvConfig.yaml src/main/resource/Schedule.yaml"
