# YWT — GitHub Copilot 活用記録

---

## Y — やったこと

- プロジェクト内でテストが必要な HTTP リクエストを Copilot にまとめさせた
- そのまとめを読ませて、Postman で使える collection.json を自動生成させた
- 同じまとめを使って、HTTP のやり取りの流れを説明するシーケンス図も作らせた

---

## W — わかったこと

- コードを自分で読まなくても、Copilot に「まとめて」と頼むだけで必要な情報を引き出せる
- まとめを一度作れば、テスト用ファイル・図など別の形式への変換も続けて頼める（連鎖が効く）
- 役立つ操作:
  - `#codebase` — プロジェクト全体を読ませるときにチャットで使うキーワード
  - `Ctrl + I` — エディタ上でその場に直接 Copilot に書かせる
  - `/explain` — 選択したコードをすぐ説明させる

---

## T — 次にやること

- ガントチャートエディタのソースコードを入手する
- Copilot に各関数・機能をサマリーさせて、「何ができているか」「何が未完成か」を一覧にする
  - 例: ドラッグで予定を動かす機能は UI だけあって保存処理が未実装、など
- 未完成の機能を特定したら、Copilot と一緒に実装を進める
  - 足りていないロジックやエラー処理なども洗い出す
- 完成した機能を現在の計画ツール（webapp）と接続するために必要な部分を整理する
  - どのデータをどこに渡すか、どの API を呼ぶかなど
  - Copilot に「このコードはどこと繋げばいい？」と聞くことで接続ポイントを探す
